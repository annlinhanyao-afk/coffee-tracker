# 生活碎片剪刀手

在任意网页上剪下一块你喜欢的内容，自动裁出一张带白边（可换色）的贴纸图片并下载到本地。跟"生活碎片"网页版用的是同一套点击式圈选、直线/曲线切换、彩色描边逻辑。

## 安装（开发者模式加载，未上架应用商店）

1. 打开 Chrome / Edge，访问 `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开"开发者模式"。
3. 点击"加载已解压的扩展程序"，选择这个 `webclip-extension` 文件夹。
4. 工具栏会出现一个粉色剪刀图标，固定到工具栏方便使用。

## 使用方法

1. 打开任意想要剪切的网页，点击工具栏上的剪刀图标。
2. 鼠标会变成剪刀样式，页面进入剪切模式（此时页面滚动被锁定）。
3. 依次点击想要圈出的边缘，点与点之间会自动连线；下方工具条可以切换"直线/曲线"、选描边颜色。
4. 点错了用撤销按钮回退一个点；不想剪了点"取消"或按 Esc 退出。
5. 点"剪下并下载"，会截取当前可见区域并裁出对应形状，自动下载一张带描边的 PNG 到默认下载目录。

## 权限说明

- `activeTab`：只在你主动点击工具栏图标时，临时获得当前标签页的访问权限，不会在后台监控你访问的网站。
- `scripting`：在你点击图标时把剪切工具注入当前页面。
- `downloads`：把剪下来的图片保存到本地下载目录。

没有申请任何"读取所有网站数据"的常驻权限。

## 已知限制

- 只能剪取当前浏览器窗口里可见的这一屏内容，不支持自动滚动拼接长图。
- Chrome 内置页面（`chrome://`、应用商店等）出于浏览器限制无法注入剪切工具。
